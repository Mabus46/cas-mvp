# Цифровой аватар спортсмена (ЦАС) — демонстрационный стенд

Работающий прототип системы «Цифровой аватар спортсмена»: верифицированный профиль спортсмена, методическое ядро тренера и прозрачная экономика методик.

Демонстрационный контур собран целиком на статических файлах: **без сервера, без базы данных, без внешних запросов**. Все данные синтетические и хранятся только в браузере посетителя (`localStorage`).

> **Демонстрационные данные.** Реальные персональные данные не используются. Имена, результаты, договоры и суммы — вымышленные.

## Как открыть

**Локально:** откройте `index.html` в браузере. Часть функций (выгрузка файла) может требовать локального сервера — в этом случае запустите в папке проекта:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

**GitHub Pages:** Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`. Через 1–2 минуты стенд будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Технические решения

- **Vanilla JS + CSS**, без фреймворков и сборки: стенд открывается двойным щелчком и не требует Node.js.
- **Локальные шрифты** PT Sans (`.woff2`) — соответствие требованию «никаких внешних CDN».
- **SHA-256 на чистом JS** — журнал операций работает даже при открытии файла с диска (`file://`), где `crypto.subtle` недоступен.
- **Трёхплоскостная модель данных**: публичная витрина / лицензируемое методическое ядро / закрытое хранилище. Ограничение доступа реализовано в модели прав, а не в интерфейсе.
- **Все расчёты воспроизводимы**: сумма долей всегда равна сумме платежа (`balanced: true`), это проверяется на каждом экране расчёта.

## Правовой контур (кратко)

Система проектировалась от ограничений. Относительно исходной концепции изменено семь положений — механики сохранены, изменена юридическая форма:

| В исходной концепции | В реализации | Основание |
|---|---|---|
| Антидопинг через анализ биометрии | исключено, только импорт официального статуса | компетенция РУСАДА/ВАДА |
| Виртуальная валюта с обменом и выводом | неконвертируемые баллы + рублёвые выплаты по договору | 161-ФЗ, запрет денежных суррогатов |
| Внутренний банкинг платформы | платёжный партнёр (НКО/агрегатор) | лицензия ЦБ |
| Наследование аватара целиком | наследуется методика и роялти, персональные данные — нет | ГК РФ ст. 1112, 152-ФЗ |
| Инвестиции с получением роялти | лицензионные договоры и целевые донаты | 259-ФЗ |
| Обмен данными со спортсменами других стран | публикация обезличенных методик | 152-ФЗ ст. 12 |
| Финансовые рекомендации от ИИ | аналитика начислений без инвестиционных советов | проф. ответственность |

Биометрия в демо-контуре **не собирается вообще**: по 572-ФЗ это возможно только через ЕБС.

Подробнее — раздел «Правовой контур» в самом стенде.

## Ограничения демо-контура

- Нет сервера: всё считается и хранится в браузере; кнопка «Сброс» возвращает исходное состояние.
- ИИ работает на правилах и статистике, нейросети не используются; это осознанное решение в пользу объяснимости.
- Платежи, выплаты и интеграции (ЕСИА, ГИС ФКиС, ЕКП, носимые устройства, ЕБС) **имитируются** и помечены в интерфейсе.
- Медицинских выводов нет: система говорит о признаках усталости и всегда отсылает к тренеру и врачу.
